# Папка Steam в инструкции экспорта

В «Экспортировать» → «Как использовать в Dota 2» есть поле «Ссылка на Steam или код друга» и кнопка «Найти папку». Поддерживаются код друга, SteamID64, ссылки `/profiles/SteamID64` и `/id/alias`, в том числе без схемы. Числовые варианты вычисляются в браузере через BigInt; ID 0, групповые ID, чужие домены и неподходящие ссылки отклоняются.

После определения кода показываем `C:\Program Files (x86)\Steam\userdata\ACCOUNT_ID\570\remote\cfg` с кнопкой копирования. В раскрывающемся поле можно изменить папку Steam, например на `D:\Steam`. Сайт не определяет диск пользователя по профилю. Путь с неподставленным ID или неверной папкой нельзя скопировать кнопкой. Изменение ввода сбрасывает прежний результат и отменяет запрос, закрытие окна тоже отменяет запрос. Последний ввод хранится только в памяти страницы, отдельно от проекта.

Модули:

- `scripts/steam-profile.mjs`: общая валидация, точное преобразование SteamID64 и сборка пути.
- `scripts/steam-folder.mjs`: форма в существующем окне экспорта; подключается из `scripts/app.mjs`, освобождается при закрытии, замене окна и dispose редактора.
- `server/steam-profile.mjs`: разрешение коротких ссылок, используется `GET /api/catalog/steam/resolve?profile=...`. Вход не требуется. Vite и production используют имеющийся API-прокси.

С необязательным **серверным** `STEAM_WEB_API_KEY` используется [ResolveVanityURL](https://partner.steamgames.com/doc/webapi/ISteamUser#ResolveVanityURL). Без ключа или при сбое API — [Steam Community XML](https://partner.steamgames.com/documentation/community_data?l=english): `https://steamcommunity.com/id/ALIAS/?xml=1`. XML официально устарел, поэтому ошибки объясняют пользователю возможность ввести код друга. Ключ не отдаётся в публичный config и никогда не имеет префикс VITE_.

Сервер строит URL только для фиксированных Steam-хостов и не следует перенаправлениям. Таймаут каждой попытки 4,5 с, ответ до 256 КиБ, кэш положительных результатов на 15 минут (до 512 записей), до 16 одновременных запросов, одинаковые запросы объединяются. API ограничивает 20 запросов/IP/минуту и 300 суммарно/минуту. Ошибки стороннего сервиса не раскрываются как есть и не содержат ключ. SteamID64 принимается строкой, чтобы не терять точность.

Проверено 28.09.2026: реальный XML и интерфейс для `https://steamcommunity.com/id/7771/` вернули SteamID64 `76561199128668433`, AccountID `1168402705`. Проверены копирование пути, другой диск, неверная ссылка и прямой код. Восемь тестов `tests/steam-profile.test.cjs` покрывают преобразования, валидацию адресов, XML/API, кэш, ошибки и HTTP-лимиты. Сценарий с настоящим API-ключом проверен подставным ответом; ключ для живой проверки не требовался. Production build и выкладка не выполнялись.
