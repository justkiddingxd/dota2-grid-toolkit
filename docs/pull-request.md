# GridStudio: лендинг, обновления редактора и восстановление проектов

PR переносит накопленные изменения поверх текущей объединённой React-студии. Главная страница становится лендингом, редактор доступен по `/editor`; пользователи могут объединять старые файлы, редактировать символы отдельно и сокращать число категорий перед экспортом.

## Изменения

- Лендинг «Сцена», авторы, favicon, десять вариантов для сравнения. На GitHub Pages ссылки ведут на `editor.html` без требования серверного rewrite; старые инструменты остаются в сборке.
- Импорт нескольких файлов с произвольными именами: добавить сетки к текущим или открыть вместо них. Восстановление нулевых/отрицательных размеров старых категорий без масштабирования координат. Сохранение черновиков, слоёв и метаданных.
- Объединение подходящих строк только при экспорте, без склеивания объектов в редакторе. Оптимизатор с оценкой числа категорий, сравнением результата и явным применением; плавный масштаб 1–800%.
- Мишень ID 127 первой среди универсалов, удаление героя крестиком. Исправления и доработки выделения, полей названий, рамок и подложки; поиск символов, подсказки конвертера и предупреждения об ограничениях Dota.
- Автосохранение в IndexedDB и localStorage, журнал незавершённой записи, копии перед обновлением, восстановление через интерфейс и защита от перезаписи между вкладками. Номер версии и инфраструктура rich-объявлений через puregram.

## Проверки и выпуск

- `npm ci --ignore-scripts --no-audit --no-fund` — зависимости установлены из lockfile.
- `npm run check` — успешно.
- `npm test` — 128 тестов успешно, включая импорт, экспорт строк, оптимизацию и восстановление после сбоев хранилища.
- Проверка публичного состава и `npm run release:check` перед коммитом. Секреты, серверные настройки, пользовательские экспорты и артефакты не включены.
- Push/PR запускают только проверки. Build и GitHub Pages переведены на ручной запуск; production build, деплой, теги и Telegram-публикация в рамках этого PR не выполняются. Версия пакета остаётся 1.0.0, изменения находятся в Unreleased.

Известное ограничение: последняя жалоба на точку ниже курсора кисти ещё требует воспроизведения и отдельного исправления. Проверки не подтверждают идентичность рендера в Dota или отсутствие просадок FPS. Каталог пользовательских сеток пока является заглушкой; публикация сеток и анимации не реализованы.
