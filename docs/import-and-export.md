# Импорт сеток и отдельные символы

В «Загрузить JSON» можно выбрать несколько файлов сразу. Название, расширение
и MIME-тип не определяют формат: редактор читает содержимое Dota JSON v3 или
проекта GridStudio. Поддерживается UTF-8 BOM. Ограничения: 20 МБ на файл,
50 МБ на одну загрузку, до 100 сеток в итоговом документе.

После чтения файлов пользователь выбирает:

- **Добавить к текущим** — сохраняет открытый документ, активную сетку,
  выделение и правки; дописывает сетки из файлов.
- **Открыть вместо текущих** — объединяет выбранные файлы в один документ.
  Два файла по три сетки дают шесть сеток, без стартового шаблона.

Операция попадает в общую историю и отменяется через Ctrl+Z. При ошибке одного
из файлов весь пакет остаётся неприменённым. Совпадающие имена получают суффиксы
`(2)`, `(3)`; сетки не заменяют друг друга. Черновики, скрытые/заблокированные
слои, фон и размеры холста native-проектов сохраняются. Неизвестные поля
категорий и сеток сохраняются; при конфликте метаданных корня приоритет у
первого/текущего файла.

## Редактирование и экспорт

В редакторе и отдельной рисовалке символы больше не объединяются автоматически.
Текст, введённый как текст, остаётся текстом; ASCII-слои сохраняют свою отдельную
идентичность. Старые автоматические `rowGlyphs` при открытии проекта
разворачиваются в независимые символы с теми же позициями и метаданными.

Только экспорт Dota JSON пытается объединить символы на одной высоте в строку.
Операция работает на копии, не меняет редактор, историю или native-проект.
Склеивание допустимо только внутри одного слоя и когда реальные измерения
шрифта позволяют воспроизвести расстояния обычными пробелами с точностью 0.01px.
Неровные промежутки, разные высоты, неизвестные метаданные и символы со сложным
контекстным/двунаправленным письмом сохраняются отдельными категориями.
Все категории без героев по-прежнему имеют размер 30 × 30 в JSON.

Счётчик холста показывает категории до оптимизации. Окно скачивания показывает
фактическое число категорий итогового JSON и учитывает его в предупреждении
о превышении 2000 категорий.

Ключевые модули: `scripts/grid-import.mjs`, `C.appendConfigs`,
`scripts/export-rows.mjs`, `C.exportDota(doc, measure)`.

## Проверка типографики

В предоставленном игровом `panorama/styles/hero_grid_new.vcss_c` обычный
`.HeroCategory #HeroCategoryName` задаёт 16px, SemiBold, letter-spacing 2px,
padding-left 4px, uppercase и цвет #808fa6. Эти значения уже использует
`scripts/dota-rendering.mjs`. 26px — отдельное переопределение `.NewPlayerPool`;
его не следует применять ко всем пользовательским сеткам.

30 × 30 в JSON — размер категории, а не размер шрифта. Визуальный размер также
зависит от масштаба игрового интерфейса/превью. Radiance и корейский fallback
взяты из игры, но растеризацию выполняет Canvas браузера. Перенос CSS не
подключает игровой движок Panorama: это отдельная система UI, а не веб-рендерер
([описание разработчика Source 2-приложения](https://sbox.game/news/panorama-experiments)).
Полное совпадение сглаживания и шрифтовых подстановок с Dota не гарантируется.
