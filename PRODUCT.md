# GridStudio

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Игроки Dota 2, создающие и редактирующие собственные сетки героев.

## Product Purpose

Сайт для кастомизации Dota 2. Сейчас доступен редактор сеток героев: группы героев, текст, рисование символами и конвертация изображений в ASCII на общем холсте.

## Operating Context

React + Vite, локальная обработка в браузере, импорт и экспорт Dota JSON. Студия помещается в окно; игровые портреты и шрифт холста приближены к Dota. Подробности движка и ограничений — в project.md.

- Focus утверждён для редактора; вариант 05 «Сцена» отдельно утверждён для главной.

## Аккаунты и рабочие пространства — актуальный локальный вариант

Новые файлы и старт без сохранённого документа открываются с пустой сеткой. Уже сохранённые проекты остаются без изменений. В редакторе единая кнопка «Изменения сохранены» открывает версии проекта; на телефоне — компактная кнопка с цветной точкой статуса. Переименование сетки находится в панели выбора сеток рядом с настройками, под холстом показывается количество категорий и оптимизация.

В карточке файла можно просмотреть каждую сетку без открытия редактора: точки сбоку, стрелки, свайп, название и счётчик. Нажатие на превью открывает именно эту сетку. Перелистывание не меняет сохранение.

Перед редактором — экран «Мои файлы» в стиле Focus: один workspace соответствует одному native-файлу, внутри может быть несколько сеток. Есть создание, импорт, поиск, копии, переименование и обратимый архив. Прежний проект остаётся отдельным локальным файлом. Вход через @grid_studio_bot необязателен даже для публикации. Кнопка сразу открывает бота, «Войти» в боте завершает вход на сайте автоматически, без кодов и второго подтверждения. Гостевые файлы не удаляются по таймеру; предупреждаем о риске очистки/вытеснения браузерного хранилища.

Новые, импортированные и прежние гостевые файлы после входа автоматически сохраняются в аккаунт, без отдельной кнопки и без дублей в списке. Локальные копии остаются. Профиль показывает аватарку Telegram и @username вместо отображаемого имени. В шапке каталога убрана ссылка на сам каталог. Уже опубликованные сетки редактируются только после привязки к аккаунту, старую секретную ссылку можно использовать для такой привязки. «Выбор авторов» заменён «Популярными» по реальным лайкам. Поставить/снять лайк может вошедший пользователь. Эти изменения пока не собраны и не выложены.


28.09.2026: антиспам — self-hosted ALTCHA без зависимости от Cloudflare; обязательна для отправок и жалоб, вход по-прежнему необязателен. Левые панели можно закреплять на широком экране с вписыванием холста; на телефонах они остаются накладными. Переименование каждой сетки доступно в раскрытом списке. Статус сохранения — по центру шапки с зелёной точкой (на узких экранах компактно); ошибки и ожидание не должны обозначаться зелёным. Мишень — первая в «Ловкости».
