# GridStudio

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Игроки Dota 2, создающие и редактирующие собственные сетки героев.

## Product Purpose

Сайт для кастомизации Dota 2. Сейчас доступен редактор сеток героев: группы героев, текст, рисование символами и конвертация изображений в ASCII на общем холсте.

## Operating Context

React + Vite, локальная обработка в браузере, импорт и экспорт Dota JSON. Студия помещается в окно; игровые портреты и шрифт холста приближены к Dota. Подробности движка и ограничений — в project.md.

## Brand Commitments

- Официальное имя: GridStudio. Сайт опубликован на gridstudio.me; главная — лендинг 05 «Сцена», редактор — /editor.
- Текст лендинга: «Grid Studio — сайт, на котором вы можете создать свою сетку героев используя встроенные инструменты и своё воображение.»
- Подпись «Сделано с ❤️ @linsissya & @dissonance» помещается в одну строку. Сердце — локальное изображение Apple, имена — кликабельные таблетки с аватаром перед именем.
- Первый аватар: https://i.ibb.co/bMh6f0mM/image.png; ссылка tg://resolve?domain=linsissya.
- Второй аватар: https://i.ibb.co/2YWsYyv2/image.png; ссылка tg://resolve?domain=dissonance.
- Две кнопки рядом: «Создать свою сетку» и «Каталог сеток». Каталог пока показывает сообщение о подготовке.
- Справа на лендинге размещён предоставленный пользователем скриншот редактора: объёмная рама, ступенчатое основание и исходный угловой знак на заднем плане. Наклон небольшой; скриншот не открывает просмотр. Вверху только логотип, внизу ссылка «Проект на GitHub».
- SF Pro Display для UI, Radiance для игрового содержимого. Без рекламных клише и выдуманных показателей.

## Capabilities and Constraints

Пять визуальных вариантов сохранены в design.html. Пользователь выбрал Focus для настоящего редактора: тёмная сиреневая палитра, плавающие инструменты, свойства и слои справа. Исходный угловой логотип сохраняется, меняется только его цвет. Для лендинга пользователь выбрал вариант 05 «Сцена» из десяти композиций Focus. Каталог пока не реализован; главная и редактор опубликованы. Примеры сеток в галерее демонстрационные; основной редактор работает с настоящими документами пользователя.

## Evidence on Hand

Работающий исходный редактор, локальные оригинальные портреты, игровые шрифты, две предоставленные аватарки. Реальных данных публичного каталога нет.

## Product Principles

- Сохранять редактируемые данные и совместимость с Dota JSON.
- Давать холсту максимум места и сохранять читаемость инструментов.
- Focus утверждён для редактора; вариант 05 «Сцена» отдельно утверждён для главной.
- Показывать возможности реальными примерами, без выдуманных отзывов и статистики.
