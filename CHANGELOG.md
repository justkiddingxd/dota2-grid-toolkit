# GridStudio

## Unreleased

Накопленные изменения относительно объединённой студии в upstream. Номер следующего выпуска будет назначен при подготовке одобренной сборки; опубликованные версии и теги этим списком не создаются.

- Лендинг GridStudio со сценой редактора, авторами и отдельным маршрутом `/editor`.
- Импорт нескольких файлов с любыми именами, объединение сеток и восстановление старых конфигов с некорректными размерами категорий.
- Символы редактируются отдельно; объединение подходящих строк выполняется только при экспорте. Добавлены оптимизатор категорий и сравнение результата до применения.
- Свободный масштаб 1–800%, мишень ID 127 первой среди универсалов и удаление героев крестиком на портрете.
- Исправления и доработки: выделение по видимому символу, поля названий, рамки, подложка для рисования, поиск символов, подсказки конвертера и предупреждения о совместимости. Отдельная жалоба на смещение точки под кистью остаётся открытой.

- Два независимых хранилища проекта в браузере; журнал последней правки на случай перезагрузки.
- Копия исходного проекта перед обновлением версии; повреждённые данные не заменяются демопроектом.
- Копии проекта можно скачать и восстановить через статус сохранения. Перед восстановлением сохраняется текущая работа.
- Защита от перезаписи между вкладками: конфликтующая вкладка сохраняет отдельную копию.
- Номер версии в справке редактора.
- Разработка и проверки локально; production build только по команде, публикация после одобрения.
- Объявления релизов через puregram: rich message, заголовок с логотипом, настоящий вложенный чеклист.
